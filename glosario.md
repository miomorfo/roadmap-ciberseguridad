# 📖 Glosario (en simple)

> Para el vocabulario en inglés de las plataformas (Submit, Hint, Task…), revisa [El inglés en ciberseguridad](ingles.md).

| Palabra | Qué significa |
|---|---|
| **2FA / verificación en dos pasos** | Además de la contraseña, pedir un código (del celular, por ejemplo). Si te roban la contraseña, igual no pueden entrar. |
| **Malware** | Cualquier programa malicioso: virus, troyanos, espías, etc. |
| **Ransomware** | Malware que bloquea o cifra tus archivos y te pide dinero para devolverlos. |
| **Phishing** | Mensaje falso que se hace pasar por alguien confiable para robarte datos. |
| **Ingeniería social** | Engañar a personas (no a computadores) para conseguir acceso o información. |
| **Filtración (data breach)** | Cuando los datos de una empresa quedan expuestos y terminan en manos de otros. |
| **IP** | La "dirección" de un dispositivo en una red. |
| **Puerto** | Una "puerta" numerada de un computador por donde entra y sale cierto tipo de tráfico. |
| **Servidor** | Un computador que entrega algo (una página, archivos) a otros computadores. |
| **HTTP / HTTPS** | El idioma que usan las páginas web. La S significa que la conexión va cifrada. |
| **Cifrado** | Transformar información para que solo quien tiene la llave pueda leerla. |
| **Hash** | La "huella digital" de un dato. Sirve, por ejemplo, para guardar contraseñas sin guardarlas tal cual. |
| **Terminal / consola** | Programa para darle órdenes al computador escribiendo, sin usar el mouse. |
| **SSH** | Programa para conectarte a otro computador a distancia y controlarlo escribiendo comandos, con la conexión cifrada. |
| **Webshell** | Una terminal de Linux que funciona dentro del navegador, sin instalar nada. La usa CyLab Security Academy. |
| **Linux** | Sistema operativo (como Windows o macOS) muy usado en servidores y en ciberseguridad. |
| **Vulnerabilidad** | Una falla que alguien podría aprovechar para hacer algo indebido. |
| **Exploit** | La técnica o programa que aprovecha una vulnerabilidad. |
| **Firewall** | "Portero" que decide qué tráfico entra y sale de una red. |
| **VPN** | Un "túnel" cifrado entre tu dispositivo y otra red. |
| **AttackBox** | El computador virtual de TryHackMe, que se abre en el navegador. |
| **Computador / máquina virtual** | Un computador "de mentira" que funciona dentro de otro o en internet. Sirve para practicar sin riesgo. |
| **CTF** | *Capture The Flag*: competencias o retos donde buscas una "bandera" escondida. |
| **Flag** | El texto secreto que demuestra que resolviste un reto. |
| **Writeup** | Explicación escrita de cómo alguien resolvió un reto. |
| **Blue Team** | El equipo que defiende. |
| **Red Team** | El equipo que ataca (con permiso) para probar las defensas. |
| **SOC** | Centro de Operaciones de Seguridad: donde se vigilan los sistemas de una organización. |
| **SIEM** | Herramienta que junta los registros de muchos sistemas para detectar cosas raras. |
| **Pentesting** | Prueba de penetración: atacar un sistema con permiso para encontrar fallas. |
| **ISO 27001** | Estándar internacional que explica cómo una organización debe proteger su información. |
| **CyberChef** | Página web para decodificar y transformar textos. Muy útil en retos de criptografía. |
| **Discord** | App de chat organizada en comunidades con canales por tema. Muchas comunidades de ciberseguridad están ahí. |
| **Extensión (del navegador)** | Pequeño programa que se agrega a Edge o Chrome, por ejemplo, el de Bitwarden. |
| **Gestor de contraseñas** | App que guarda todas tus contraseñas de forma segura, protegidas por una sola contraseña maestra. |
| **Dominio** | El nombre de una página web, como `google.com`. Lo que importa es la parte final, justo antes de la primera `/`. |
| **GRC** | Gobierno, Riesgo y Cumplimiento: la parte de normas, políticas y gestión. |
