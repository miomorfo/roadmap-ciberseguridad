# 🇬🇧 El inglés en ciberseguridad

Casi todo en ciberseguridad está en **inglés**: las plataformas, los cursos, las herramientas, los mensajes de error, la documentación y las noticias. Incluso quienes trabajan en Chile leen y buscan en inglés todos los días.

Por eso, **practicar inglés es parte de aprender ciberseguridad**, no algo aparte. No necesitas saber mucho para empezar: el inglés técnico usa pocas palabras que se repiten una y otra vez, y las vas a aprender usándolas.

## Cómo practicarlo mientras avanzas

1. **Lee primero en inglés.** Aunque no entiendas todo, intenta captar la idea general. Te vas a sorprender de cuánto entiendes por contexto.
2. **Busca solo las palabras que te traban.** Usa un diccionario como [WordReference](https://www.wordreference.com/es/) o el traductor, pero para palabras o frases sueltas, no para la página completa.
3. **Haz tu propia lista de palabras.** Cada vez que busques una palabra, anótala. A las pocas semanas vas a ver que se repiten siempre las mismas.
4. **El traductor de página completa, solo como último recurso:** úsalo cuando una explicación larga de verdad no se entiende. Después vuelve a leerla en inglés.
5. **Busca en inglés.** Cuando te trabes, busca en Google en inglés, por ejemplo, `how to read a file linux`. Hay muchísimas más respuestas que en español.
6. **Videos con subtítulos en inglés.** En YouTube hay mucho contenido de ciberseguridad. Activa los subtítulos en inglés (no en español) para ir acostumbrando el oído y la lectura.

⚠️ **Nunca traduzcas comandos, nombres de archivos ni respuestas.** Si usas el traductor del navegador, puede cambiar `cat flag.txt` por "gato bandera.txt", y eso no funciona. Los textos en **recuadros grises** se escriben siempre tal cual.

## Palabras que vas a ver todo el tiempo

### En las plataformas

| Inglés | Español |
|---|---|
| Sign up / Log in | Registrarse / Iniciar sesión |
| Room / Path | Sala / Camino (curso) |
| Task | Tarea |
| Challenge | Reto, desafío |
| Hint | Pista |
| Submit | Enviar |
| Answer | Respuesta |
| Start / Stop / Terminate | Iniciar / Detener / Terminar (apagar) |
| Download / Upload | Descargar / Subir |
| Walkthrough | Paso a paso guiado |
| Writeup | Explicación de cómo alguien resolvió un reto |
| Free / Premium / Subscribers | Gratis / De pago / Para suscriptores |
| Beginner / Easy / Medium / Hard | Principiante / Fácil / Medio / Difícil |

### En las explicaciones y la terminal

| Inglés | Español |
|---|---|
| File / Folder (Directory) | Archivo / Carpeta (directorio) |
| Command | Comando |
| Password / Username | Contraseña / Nombre de usuario |
| Permission denied | Permiso denegado (no tienes permiso) |
| No such file or directory | No existe ese archivo o carpeta |
| Command not found | Comando no encontrado (está mal escrito o no existe) |
| Connection refused / timed out | Conexión rechazada / se acabó el tiempo de espera |
| Hidden file | Archivo oculto |
| Encrypt / Decrypt | Cifrar / Descifrar |
| Encode / Decode | Codificar / Decodificar |
| Vulnerability | Vulnerabilidad (falla) |
| Attacker / Target | Atacante / Objetivo |
| Threat | Amenaza |
| Breach / Leak | Filtración, brecha |
| Find / Search | Encontrar / Buscar |

Agrega las tuyas a medida que aparezcan. 💪
