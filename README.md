# 🔐 Ciberseguridad: ruta para probar sin perderse

Hola 👋 Esta es una guía para **descubrir si la ciberseguridad te gusta**, sin tener que saber nada antes.

No es una carrera ni un curso obligatorio. Es una ruta para **ir probando de a poco**, con pausas para preguntarte "¿me está gustando esto?". Si en algún momento la respuesta es "no", también está perfecto: habrás aprendido a protegerte mejor en internet, y eso sirve igual.

---

## 🧰 Qué necesitas

- Un **computador** con internet (Windows sirve perfecto).
- Un **correo** para crear cuentas en las plataformas.
- **Nada más.** Casi todo funciona en el navegador (Edge o Chrome). La única excepción es el juego Bandit de la Etapa 2, y ahí está explicado paso a paso.

## 🖱️ Cómo usar esta página

- Haz clic en el nombre de cada etapa para abrirla.
- Al final de cada etapa hay un link **"← Volver al inicio"** para regresar aquí.
- Las palabras en **negrita** que no conozcas probablemente estén en el [glosario](glosario.md).
- Muchas plataformas están en **inglés**. En Edge o Chrome, haz clic derecho en la página → **Traducir al español**. No tiene nada de malo usarlo.

## 🧭 Reglas del juego

1. **Está bien no entender.** Todos se pierden al principio. Si algo te frustra mucho rato, pregunta.
2. **Todo es gratis.** No pagues nada hasta llegar a la Etapa 4 y estar segura de que te gusta.
3. **Solo practicas en lugares hechos para practicar.** Nunca en cuentas, redes o páginas de otras personas (lee la Etapa 0).
4. **No hay que hacerlo todo.** Si una actividad te aburre, sáltala. Esta guía es un menú, no una lista de deberes.
5. **Celebra.** Cada reto resuelto cuenta. 🎉
